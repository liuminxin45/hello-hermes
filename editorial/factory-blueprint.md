# Hermes Agent 工厂实习馆：五章观察蓝图

本轮重构更新于2026-10-29。定位是让会用聊天 AI 的读者，通过一份委托的处理过程理解 Agent 的系统关系，再用一次新会话观察经验复用。无需代码、安装或模型密钥；保留可旋转的工厂、导师、追问、实景照片、报告、自测与纪念证明。原十八章图文资料继续由 `library.html` 进入，原 URL 保留。

本文件记录工厂阶段的产品合同。五章重构见 [重构实施清单](redesign-implementation.md) 和 [用户报告快照](reviews/2026-10-29-redesign-source.md)。本轮视觉与动态教学优化按 [逐项清单](visual-interaction-implementation.md) 和 [优化指导原件](reviews/2026-10-29-visual-interaction-source.md) 推进。代码已实现、浏览器可用、真人理解及实体设备性能是四种不同证据，不相互替代。

## 委托与材料

第一份委托：核查三份不完整线索，合并同源消息，写不超过三条的简报；区分确认与未知，只交草稿，不发布或通知。

| 材料 | 作用 |
|---|---|
| S1 / S2 | Atlas 的资讯与同源转载，不能算两件独立事件 |
| S3 | 把申请预览夸大为全面开放，同时简略提到 Delta 更新的待核摘要 |
| A1 / A2 | 工具实际读回的 Atlas 原始公告与申请条件：可申请，仍需审核 |
| D1 | Delta 原始说明：新增 PDF 和 Markdown 检索，不扩展为所有格式或完美召回 |
| A3 | 第二次委托的新公告：新增审计日志与只读权限配置，申请审核条件仍在 |

全部品牌、公告、工具结果均为固定虚构教材。首次正确草稿只有 Atlas 与 Delta 两条独立消息，来源、限制和未知项留在各条内，不用“去重说明”或未知项凑第三条。首屏以“三条消息里有重复与夸大，需要查证后交出草稿”的任务开场，只保留主入口、短说明与输入输出预览。预览不生成本次任务完成态；完整成品样例、来源和演示边界按需展开。受众偏好仍可选择并实际改变草稿侧重点，但不要求入场前先读配置；昵称留在本机设置，可留空。

第二份委托只在第五章展开：继续跟进 Atlas，但这次给研发同事看，多一些技术细节，仍只做草稿。保留必要的请求、读取、核查与交付动作，不重复第一轮参观路线。旧事实只作线索，最新结论须由 A3 支持。

## 五个观察章节

| 观察章 | 眼前的变化 | 读者动作与完成依据 |
|---|---|---|
| 1 接到委托 | 待核线索变成读取请求，尚未取得原文 | 生成请求，实际观察请求事件；分清提出动作与执行 |
| 2 查证与回路 | 工具读回原文，转载合并，夸大被修正 | 执行读取并核对；实际观察原始依据改变结论 |
| 3 有限的工作台 | 完整档案与本轮选入内容并列 | 完成当前输入/档案对照；短任务不用压缩也可继续 |
| 4 交付并留下经验 | 两条草稿通过已定义检查，保存或拒绝的选择留痕 | 交付后明确选择偏好与方法是否保存，观察结果与保存决定 |
| 5 新会话中的复用 | 旧整段聊天退出，相关条目按需进入新输入，再核实新事实 | 选择是否启用跨会话资料，观察实际读取、当前要求优先及新草稿 |

主线直接解释模型请求、程序调度、工具执行、反馈循环、四类资料、摘要风险、复用非训练及授权边界，不能依靠追问补齐核心题前置知识。每章有一个白话疑问与一个目标主操作；一个概念内的请求、派发、读取、回执由教学编排接续，不让访客逐个调度。保存偏好与方法仍须明确选择。完成条件依赖观察或对照证据，不能靠停留时间或读完字幕解锁。

仍有入口、调度、模型判断、工具、档案、用户资料与技能、上下文、交付、过程观察九类部件。它们是具象比喻，不宣称与源码一一对应，也不将参观顺序当作真实调用顺序。导师负责解释；工具工人不默认表示多个独立 Agent。复盘只记录可观察事件，不表现自动训练。

## 状态、事件与本机保存

v3 使用独立的 `task`、`tour`、`learning`：

- `task` 保存两次会话、材料、草稿、长期条目、实际读写与事件。
- `tour` 保存当前章节、观察事件、暂停与可选教学回放。
- `learning` 保存已观察事件、完成章节、对照、实际追问、照片、自测、个人解释与自评。

任务动作先产生带稳定 ID 的事件，事件记录输入、结果、证据编号及学习目标。呈现层把事实编排成可采样片段，场景、侧栏、地图读取同一条因果证据和同一观察时钟。事实已产生时，排队结果仍须到对应节拍才向界面揭示。观察位、回访、提问、跳动画与示意循环只改变观察；不得取新资料、改结论或重复写入。跳过如实记录为略过/查看结果，不追认为观察了全过程。

偏好与技能默认未勾选。拒绝保存不生成相应新条目；会话历史单独留档，不等于同意写入长期偏好。保存条目、写入事件和后续读取以 ID 对应。已保存核查方法可在统一面板里选择修订，明确保存后产生新写入事件；下个会话实际读取修订后的步骤。它是可选操作，不进入必经主线，也不自动执行方法。新会话从新委托与常驻规则开始，不偷偷带入整段旧上下文。保存过不等于本次已经使用；只有实际读取的条目进入本轮输入，当前明确研发要求覆盖旧业务偏好。

“最小工具型 Agent”对照保留当前上下文、模型、工具与反馈循环，只关闭跨会话资料。它仍能完成工具任务，不代表所有其他 Agent 缺少记忆，也不证明 Hermes 独占这些机制。

浏览器 IndexedDB 只存本机数据，当前键为 `factory-v3-active` 与 `factory-v3-library`；历史记录与不兼容版本应只读保留。记录同时写 `schemaVersion=3` 与任务 `scenarioVersion`，恢复须检查版本和结构。常驻指令、可用工具说明和当前用户委托分别展示，不把委托混作系统提示。v1 礼盒、v2 调查及不兼容 v3 不自动继承完成态，不得静默覆盖；归档/恢复实际链路见实施清单待验项。存档失败要提示，并允许导出当前页面记录。清理浏览器数据可能导致本机记录丢失。

## 上下文与失败对照

主线只要求看清“完整档案存了什么”和“这一轮实际选入什么”。容量有限、摘要有损，原文存着也需要实际查回；不将摘要遗漏自动说成已经恢复。

可选长过程回放使用100格容量、70格示意线和20格预留。约26秒的演示从25格分批增长到35、45、55、65、70；增长时最近交接滚动，旧交接进入中段，工具请求/结果按教学规则成对保留。到示意线后才锁定本次规则、Head、Tail：5+10+45+10=70。整理员将中段重写为带条件、来源和待办的10格摘要，交回后总占用为35；原始档案与来源ID不改写。摘要明确保留“仍需申请审核”“PDF / Markdown”“仅草稿，不发布”，不能只有无损缩小动作。坏摘要刻意丢失这些条件，供回查。数字是缩比教学格，不是真实 Token 消耗或 Hermes 默认值；首尾保护仅指本次选定集合，不把Tail表现为整个增长过程永久不变。整理员不代表必有独立子Agent。

引擎支持读取失败与错误版本，失败不添加成功依据，未经核查不能交付成功草稿。真实运行、真实压缩模型、外部发布及后台持续任务都未接入。预算变化、词法/预编语义召回、三类工具回执已加入可选受控对照函数，明确不运行真实数据库、嵌入模型或网络API；界面接入与验收仍留在清单，不能用问答文案冒充已经执行的实验。再次整理、工具配对、Skill维护和实现扩展已有按需追问；通用架构选择与固定版本Hermes依据明确分开。

## 追问、操作与三维表现

只有一套追问面板，首层两个相关问题，更多问题按理解原理、Hermes 怎么做、失败与边界分类。回答分直接回答、眼前证据、适用边界、回到任务四步。检索只查已编辑问题，未命中说明暂未覆盖，不伪装实时模型导师。打开追问保存一次原观察位，连续问题只替换细节目标；关闭恢复原位并清理，不逐题堆镜头栈。暂停采用user、question、report、exam、hidden、contextLost独立原因；关闭追问只移除question，保留原有user暂停。暂停的是本机教学，不是外部工具。

继续与追问是主操作，暂停、退出、跟上导师和全景持续可达；资料、日志、回放、本机记录进入次级页。桌面采用真实场景列与约360px右侧栏，小地图在栏顶，导师短句、结果和深入资料在其下滚动，主操作在栏底。画布、相机、投影与拾取以真实场景容器为准，侧栏不盖设备。窄屏采用上场景、下讲解的真实分区，场景约55%以上是起始目标，需适应320px、横屏与200%缩放。收起只重排，不暂停；预设观察位让手机读者无需自由行走。原生按钮、表单、焦点样式及Canvas外状态提供键盘和文字路径。

视觉由统一场景状态控制，聚焦不启动设备，任务状态与示意状态分开。默认一个焦点、最多两个当前事件配角。关注度实际作用于本材质初始不透明度：焦点乘1，关联约乘0.60，背景约乘0.18，遮挡背景再乘约0.35。原玻璃保留初始透明度，全景恢复颜色、透明、深度与可见性。背景同时减弱内件、标签、人物和阴影，保留空间轮廓；不以全厂多层透明保证可读。300–600ms过渡是初始标定，仍需视口验收。

轮廓表达关注，局部灯、文字和动作表达Running、Waiting、Completed、Error。完成保留结果物，不把循环示意写成业务执行中。常规动作按到位、准备、处理、交接、结果、保持六拍呈现，首次约6–9秒，可暂停、重看、跳过；循环不新增事件。工人按toolRequest、toolResult、toolError、memory、skill、history、compress语义映射，偏好灯与方法灯独立。人物有转向、步行、交接与接地关系，不表演隐藏思维。结构线不等于传输，有事件才出现带来源ID的卡片；轨迹只表示记录，不播放训练。独立材质或参数避免每帧新建材质、几何和纹理。

阅读和处理阶段镜头稳定，无常驻环绕；到站、动作、细节机位按设备及输入输出构图，主要聚焦完成后才开始动作。手动接管后不抢回，明确跟上导师才返回。三维只留短牌与资料ID；DOM标签只留焦点及至多两个关联设备，执行视锥、碰撞和安全区检查。SVG地图从同一NODES/FLOWS与呈现快照派生，方位稳定、至多强调2–3条活动关系，点击只读观察，不执行业务或完成章节。减少动态使用同一分镜关键帧，隐藏暂停时钟，返回不补跑。视觉舒适度必须由真实屏幕检查，纯状态测试不能代替。

## 报告、自测与离场

默认报告展示两次委托结果、请求/反馈、当前输入/档案、新会话复用三类最新实景，最近最多三条实际追问、个人解释和自评、首次与含复习最佳成绩、按核心目标关联的后续阅读。没有照片或问题就明确缺失，不补预制图或推荐问题。全部事件、全部相册、完整问答、各次作答及版本来源收进折叠附录。

实景来自真实渲染场景，目标1920×1080、16:9，用独立捕获尺寸与相机构图，不拉伸窄画布。工具结果可见、摘要替换、复用读回等语义标记触发照片，记录真实尺寸、片段ID、事件ID、时间、说明和回放标记。没拍到则记录缺失。报告只嵌入安全本机图片、转义个人文本，导出HTML自包含；失败可重试。观察、完成对照、自测通过分开，不称已掌握。

默认六道核心情境题覆盖请求与执行、反馈、四类资料、摘要风险、跨会话复用与授权；复习切换等价新情境，保留首次与最佳成绩。解释题由本人填写与自评，不由固定脚本冒充模型判分。完成五章关键观察且任一次完整核心自测达到80分，可生成本机 PNG 纪念证明；证明不代表职业资格。考核无倒计时，姓名可空，报告、下载或考试都不阻碍保存进度并离开，保留导师告别。
