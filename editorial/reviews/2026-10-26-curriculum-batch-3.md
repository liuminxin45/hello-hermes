## 固定版本与资料

Hermes v0.22.5，提交 `bf0203a794a07aac3ff764972ab9087baa4e4f4e`。本批 10–13 根据相应官方文档核对。新增读取同一提交的 Gateway Internals 与 Cron Internals；没有把主分支变化混入。案例、模型对比情境和任务包均为教学设计，不是性能测试或实际机器人部署。

## 核心边界

- 10：核对 Provider Runtime Resolution。区分能力、地址/凭据/协议和运行程序；不同原生访问路径、响应归一、辅助模型与任务配置单独解释。回退文档有新旧路径描述交叠，正文只保留已能共同确认的条件式回退，不将某条链长或具体次数推广为全系统保证。
- 11：核对 Profile、Bot Mode 与网关入口。Profile 的持久 home、Bot roster 与规范会话、平台账号、会话路由分别解释。未把目录归属当成沙箱；未将配置复制当成空白身份或物理独享外部服务。Bot Chat 的 `/new` 与普通会话区分；隐藏不是停用。
- 12：核对调度用户文档及内部生命周期。新运行、技能加载、工作目录、配置预检、执行认领、错过时间点与独立投递分别说明。不把 `ok` 简单解释为人类已经收到，投递抑制、无目标和队列结算有不同含义。不宣称重启会逐项补齐积压。
- 13：核对委托文档。新上下文、项目说明、继承工具与角色限制、结构校验、后台完成入队、分组不是依赖、默认共享目录与可选 Git 工作树、进程归属与取消链逐项区分。主案例不强行使用多 Agent。
