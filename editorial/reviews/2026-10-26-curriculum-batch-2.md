# 课程重构第二批核对记录

## 基线与范围

沿用本轮实际查询的最新稳定版 Hermes v0.22.5，固定提交 `bf0203a794a07aac3ff764972ab9087baa4e4f4e`。本批发布 05–09，正文不提供源码跳转。实现依据保存在版本记录，不将教学推演当成实际模型运行。

## 逐章核对

- 05：对照 Agent Loop 文档及本轮固定提交的循环与终止相关模块，分清模型根据工具反馈作选择、运行程序处理请求与预算的职责。模型轮次、请求重试与工具次数不混算；不声称存在每次必经的独立规划模块。案例结果来自固定材料推演。
- 06：核对 Context Compression and Caching 文档。区分上下文引擎、会话历史清理、工具结果裁剪、摘要和服务端提示词缓存。压力估计不冒充精确词数；不写死易变阈值；压缩失败可能保留原历史或按条件降级，不宣称任何失败都会自动丢弃历史。
- 07：读取固定提交 Session Storage 文档。普通受管理路径由会话权威组织规范写入，不能从多个工作进程存在推导成任意并发写入。同一会话可有多次运行；压缩的活跃代次切换和子会话继承不是同一件事。输入归属标记避免的重复记录不等于对外动作恰好执行一次。
- 08：核对 Memory 文档。精选记忆与用户画像有容量，超限由调用者处理；持久写入、会话起点的冻结快照、工具返回的当轮反馈是三个时间点。将待审批与已写入分开，不假定所有配置都立即落盘或改写当前会话前缀。
- 09：核对 Skills 与 Curator 文档。渐进发现与展开正文、方法文件与模型权重、多个来源与写入目标分别说明。没有把外部来源一概称为只读；整理的确定性生命周期部分与可选模型合并分开。技能草案明确适用条件与验收，不保证保存一次就会自动改进。
