# 首版逐章与全书校核 · 2026-10-23

范围：十四章、序言、附录、系列图解和 Codex 本地维护流程。内容采用固定版本官方资料与针对性源码阅读；教学任务没有冒充真实模型运行。本记录是本次制作与自检结果，不代表外部同行评审或 Hermes/OpenClaw 的性能实测。

## 逐章检查

| 章 | 核心检查与修订 |
| --- | --- |
| 01 | 将工作流与 Agent 的差别落在控制方式；避免把所有聊天产品当作无工具聊天；分开行动意图与执行 |
| 02 | 按责任跟任务，说明核心外观入口与实际循环模块不同；分开界面显示、状态保存与恢复 |
| 03 | 分开工具成功、循环结束和任务完成；重绘错误的终止回环箭头，图中交付与说明限制都没有返回循环 |
| 04 | 区分 Tool、MCP、Plugin、Skill；工具结果不能自行升级为授权指令 |
| 05 | 区分保存资料与当前输入；保留压缩损失、来源定位和缓存条件，不写无依据的收益倍数 |
| 06 | 核对基础记忆的会话启动快照、写入与生效时间；分开记忆、检索和历史恢复 |
| 07 | 核对 Curator 的范围和模型辅助整理配置；技能改进不等于模型权重训练 |
| 08 | 分开模型、提供方与运行适配；按完整任务讨论成本，未给未经测量的排名 |
| 09 | 分开 Profile、Session、Bot Mode、平台 bot 与子 Agent；目录边界不等于系统权限边界 |
| 10 | 核对触发、执行、保存和投递的区别；说明未知状态与重复副作用，保留无模型脚本模式 |
| 11 | 说明子 Agent 的上下文交接、共享资源与汇总责任；补充受理句柄与完成投递的区别 |
| 12 | 按具体审批模式解释，不宣称所有危险命令必定弹窗；区分授权、沙箱与核实 |
| 13 | 分开静态阅读、测试运行、真实任务回放；用失败情境检查交付，未伪造运行结果 |
| 14 | 对照双方固定版本；说明 OpenClaw 同样有记忆整理和技能机制；按生命周期与配置讨论差异 |

每章均有具体案例或状态对照、两张以上配图、一个不写代码的小练习、章末要点及两个带参考答案的理解题。部分责任图有意跨章复用，图注明确本章使用它解释的边界。

## 拉通检查

前两章只引入任务与责任图；3–7 章沿行动、信息和经验递进；8–11 章补模型、身份、时间和分工；12–14 章回到权限、证据与比较。每章结尾衔接下一个实际问题，后章回指前置概念，术语表保持相同定义。

全书使用同一个技术简报案例；“教学示意”“固定版本依据”“未做真实模型运行”保持明确。序言、来源页和维护技能使用相同核对口径，来源页直接读取各章记录，不维护另一套版本表。
