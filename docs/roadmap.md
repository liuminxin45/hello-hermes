# 学习路线与发布进度

新版从会用聊天 AI 的起点，逐步走向理解系统关系、推演状态、解释设计取舍和迁移分析。主线按前置知识安排，最后完成一个不要求编程的综合项目。

课程分批发布，已完成单元可直接阅读，尚未完成的内容不会出现在阅读导航和搜索中。每章写明要解决的问题与学完能做的事；旧版材料保存在[旧版档案](./legacy.md)。

阅读时跟着[同一份消息简报](./casebook.md)逐步增加能力。能够解释原理，还要能在输入变化时判断下一步；理解题与案例产物用于检查这一点。
